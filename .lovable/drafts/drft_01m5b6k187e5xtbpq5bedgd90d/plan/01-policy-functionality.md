# Finish the policy functionality

Continue the approved club admin build without revisiting names or visual styling. Finish the remaining policy work before starting People.

## What this adds
- **Require Gradus documents:** clubs can require sign-offs on eligible Gradus library documents as well as their own uploads. Each club controls its own audience and version; one club’s settings or sign-offs never affect another club.
- **Deadline tracking:** the Policies table and overview use the same deadline. The earliest deadline among active packs containing a document applies; an outstanding sign-off past that date makes the overview Blocked. Signed documents do not create overdue tasks, and archived packs do not contribute deadlines.
- **Proof packet:** keep the CSV download and add a PDF containing the document reference, audience, version, current sign-offs, outstanding people, retained earlier sign-offs, and guardian-on-behalf-of-athlete attribution. Include the original PDF where available; link resources retain their source address.
- **Member flow:** coaches, parents and athletes can open and acknowledge the required document using the existing flow. Parents continue signing on behalf of under-18 athletes. Reminders target only outstanding eligible signers.

## Keep existing Gradus patterns
Reuse the current tables, filters, buttons, resource controls and detail sheets. Keep the desktop-first layout, paper surfaces, Garamond headings and semantic pen colors. No naming changes or extra explainer subtitles.
