# Drop the "Go to [rink]" chip from Following cards

The chip on each followed-skater card jumps to the Live tab with that rink selected. It made sense when Live was the only place to see what was happening; now each Following card already shows the rink, the event, the start position, and the live state line — the jump mostly loses the viewer's place in the list they came to read.

Recommendation: remove it. Following becomes a clean read (state, event, rink, position, score), and the Live tab stays reachable one tap away in the segmented toggle, where its own rink chips do the same selection.

What stays on the card: the Following/Follow toggle and, once a protocol exists, Score detail.
