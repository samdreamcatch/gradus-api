## 5. Conflict hotspots and how to resolve them

- **`src/routeTree.gen.ts`** (web #206, #207, #211 each add a route): never hand-merge. Take main's copy (`git show origin/main:src/routeTree.gen.ts > src/routeTree.gen.ts`), then regenerate with router-generator **1.167.40**, the version Lovable pins (memory `gradus-routetree-regeneration`). Run it on a clean `origin/main` worktree first: no diff means it's the right version. In an empty folder in your scratchpad, run `bun add @tanstack/router-generator@1.167.40`, save this as `gen.mjs`, and run `bun gen.mjs <web worktree path>`:

  ```js
  import { Generator, getConfig } from "@tanstack/router-generator";
  const cwd = process.argv[2];
  const footer = `import type { getRouter } from './router.tsx'
  import type { startInstance } from './start.ts'
  declare module '@tanstack/react-start' {
    interface Register {
      ssr: true
      router: Awaited<ReturnType<typeof getRouter>>
      config: Awaited<ReturnType<typeof startInstance.getOptions>>
    }
  }`;
  const config = getConfig({ routesDirectory: "src/routes", generatedRouteTree: "src/routeTree.gen.ts", target: "react", routeTreeFileFooter: [footer], disableLogging: true }, cwd);
  await new Generator({ config, root: cwd }).run();
  ```

  If main's footer ever changes, copy it from the end of main's `src/routeTree.gen.ts`.
- **`docs/api/openapi.json`, `scripts/openapi.ts`:** keep both imports in `scripts/openapi.ts`, then `bun run openapi`. New routes must be imported there, or they're silently missing from the contract.
