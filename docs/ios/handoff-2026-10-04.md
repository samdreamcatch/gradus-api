## 8. Conventions and gotchas, new this session

- **Invented names only** (§3). Before adding any person to mocks, fixtures, demo data or screenshots, invent the name and run `git grep -w -i <name>` in both repos. If unsure whether a name is real, ask Mariah. Squash-merge messages must not carry the real names either.
- **Optional contract fields across the deploy gap.** Xcode Cloud ships iOS `main` automatically while Lovable publishes by hand, so a response field the iOS app reads must be optional in the zod contract (the server always sends it). Otherwise the generated Swift client fails to decode the whole response from an unpublished server. Enums are closed: add a field rather than a value.
- **`bun run build` rewrites the whole `src/routeTree.gen.ts`** (about 6,700 lines of reordering). For a new route, add only its lines by hand, mirroring an existing route of the same parent, and confirm `bun run build` passes without committing its output. Review agents have run the build too: check `git status` after a review.
- **`webhook_receipts` doubles as the event and audit store.** It has no constraint on `source` and is UNIQUE on (`source`, `external_id`). The restore uses `app_store_pause`, `admin_restore` and `admin_restore_log`. The notification receipt check uses `source = 'app_store'` only. The five-year purge from #179 deletes rows of **every** source by age, so nothing that has to outlive five years can live there. An `admin_restore` exemption older than that expires while its withdrawal stays on file, and the next re-report would pause the athlete again. Worth a follow-up before the first purge could reach a restore.
- **Timestamps:** Postgres returns `+00:00` and JavaScript writes `Z`. Compare instants (`Date.parse`), never strings.
- **iOS tests:** `swift test` inside a package fails on the macOS platform floor and dirties `Package.resolved`. Always run `xcodebuild test -project Gradus.xcodeproj -scheme Gradus -destination 'platform=iOS Simulator,id=4E63D3FF-E87A-4129-9769-D0B994E9107A'`.
- **zsh:** `echo ==` (or any word starting with `=`) is an error; use `echo "--"`.
- **Workflows and subagents** still stall on API timeouts here: one agent in four or five, with no progress for 10 minutes or more. Keep the reading lists short, watch `journal.jsonl` and the agent file times, stop and redo by hand when one stalls, and never let an agent edit files that another agent is reviewing.
- **Squash merges in iOS move `Contract/SOURCE_COMMIT`**, so sibling PRs conflict. Re-run `scripts/sync-contract.sh` against web `main`; never hand-merge generated files.
- **Review agents can leave side effects.** A reviewer ran `bun run build` and left a regenerated `routeTree.gen.ts` in a worktree. Tell reviewers not to build, and check `git status` in every worktree after a review.
- **Repo rules (web):** `main` needs a PR and the `semgrep-cloud-platform/scan` check. Squash is fine for feature PRs; Lovable's own `lovable-sync` branch must be merged with a merge commit.
