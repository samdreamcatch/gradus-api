## 3. What this run built

- **AP1–AP4** (decision #35, PRD §10.10): an athlete (including a minor, #37) writes their own plans, text or voice; coaches see them read-only; parents see them; a share page says "Plan by *first name*"; the web shows nothing new (`includeAuthored` gating in the shared loaders). The voice path transcribes and discards: audio goes to the transcription request only, logs carry lengths, the idempotency row is redacted, and **the iOS app never keeps an athlete's clip** (offline it drops it with a plain message).
- **Retention**: the 13-month `email_send_log` sweep; the kws contract migration (drafted).
- **W1 iPhone**: the full read of a plan, in order, from `GradusCore` (`PlanNarration` is platform-neutral and is what the watch will reuse), a pinned player bar with a live caption and labelled controls, three speeds, the list follows the move being read, VoiceOver focus handled, the recorder and the narrator never run together.
- **W0**: the `GradusWatch` target (watchOS 11, `training.gradus.app.watchkitapp`, independent) embedded in the iPhone app; `GradusAPI`, `GradusCore`, `GradusDesign`, `GradusWidgetData` build for watchOS; the watch gets its own session from the phone (`POST /auth/companion`, pull model over WatchConnectivity, tokens only in a live message and its reply, never queued); sign-out on either side signs out the other, queued and live.
- **W2 web**: `GET /coach/up-next`.

## 6. Conventions and gotchas new this run

- **Idempotent routes persist the whole response for 24 h** in `api_idempotency_keys`. Anything that returns words that must not be kept needs `idempotencyStoredBody` (see `athlete-voice.server.ts` `withoutWords`).
- **Review lenses stall in this project** (see the workflow-agent note): do privacy and RLS review by hand, keep reading lists short, and never let a review agent run `bun run build` (it reorders `routeTree.gen.ts`). `scripts/openapi.ts` has an explicit route import list.
- **`routeTree.gen.ts` can be regenerated instead of hand-edited.** Lovable's "Applied pending migrations" commit on 2026-10-05 regenerated it with `@tanstack/router-generator` **1.167.40** (the version in `bun.lock`; the hoisted 1.167.17 in a stale `node_modules` orders it differently). Running that version's `Generator` with `routesDirectory: 'src/routes'`, `generatedRouteTree: 'src/routeTree.gen.ts'`, `target: 'react'` and Start's footer (the `declare module '@tanstack/react-start'` block at the end of the file) reproduces `main` byte for byte, so a rebase conflict in the file resolves as: take `main`'s copy, run the generator, `git add`. The diff then shows only the PR's own routes.
- **Diff migrations against `pg_get_functiondef` from a replayed database**, not the file you think you rewrote: a stale trigger body regressed once.
- **Opaque surfaces over live content.** The translucent `GradusColor.card` over a scrim lets the page show through the words (the voice overlay had it); use `popover` for anything that floats.
- **Watch simulator recipe.** `xcrun simctl create` a Series 10 (46 mm and 42 mm are available) on the watchOS 27 runtime and `xcrun simctl pair` it with an iPhone simulator. Installing the phone app does **not** update the watch app: `xcrun simctl install <watch> Gradus.app/Watch/GradusWatch.app` yourself. Run both with `-GradusMock coach`. `simctl ui content_size` is unsupported on the watch (pass `-UIPreferredContentSizeCategoryName UICTContentSizeCategoryAccessibilityXXXL` at launch); sign the phone out with a small XCUITest against Settings → Sign out.
- **WatchConnectivity.** `sendMessage` reply and error closures must be `@Sendable` (a main-actor-inferred closure crashes on the framework's queue with a libdispatch assertion). Activation and reachability lag `activate()`: `WCSessionLink.send` waits up to 4 s. watchOS ignores the asset catalog's dark appearance, so `generate-colors.swift` emits dark literals under `#if os(watchOS)`.
- **XcodeGen.** Never retype the Supabase publishable key into `project.yml` (a typo got in once): copy the line. `swift test` in a package fails (macOS floor) and dirties `Package.resolved`: test with `xcodebuild test -scheme Gradus` and `git checkout` the file.
- **XCUITest at AX5:** `typeText("\n")` flakes (an edit-menu bubble appears); tap the keyboard's Done key.
